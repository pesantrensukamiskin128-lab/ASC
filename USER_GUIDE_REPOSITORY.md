# User Guide: Repository Publik

Repository adalah halaman publik yang menampilkan karya ilmiah yang telah dipublikasikan oleh lembaga. Repository dapat diakses oleh **siapa saja tanpa perlu login**, namun untuk **mengunduh file lengkap** pengguna harus login terlebih dahulu.

---

## Konten Repository

Repository menampilkan tiga jenis karya yang telah dipublikasikan:

| Jenis | Keterangan |
|-------|-----------|
| **Penelitian & Pengabdian** | Hasil penelitian dan pengabdian yang didanai hibah |
| **Skripsi** | Skripsi mahasiswa yang telah lulus sidang |
| **Karya Dosen** | Buku, modul ajar, HKI/paten, penelitian/pengabdian mandiri |

---

## Akses Repository

### Untuk Pengunjung Umum (Tanpa Login)

1. Buka URL aplikasi di browser.
2. Halaman utama akan langsung menampilkan **Repository** dengan daftar karya yang dipublikasikan.
3. Pengunjung dapat:
   - Melihat daftar semua karya yang dipublikasikan
   - Membaca judul, abstrak, nama penulis/peneliti, tahun
   - Menggunakan fitur **pencarian** dan **filter**
   - Membuka halaman detail setiap karya

### Untuk Pengguna Terdaftar (Setelah Login)

1. Login ke aplikasi menggunakan akun dosen, mahasiswa, atau staff.
2. Buka menu **Repository** atau langsung ke halaman utama.
3. Pengguna dapat:
   - Semua fitur pengunjung umum
   - **Mengunduh file lengkap** (laporan, skripsi, paper, dokumen karya dosen)

---

## Fitur Pencarian & Filter

### Kotak Pencarian

Ketik kata kunci di kotak pencarian untuk mencari berdasarkan:
- Judul karya
- Abstrak
- Kata kunci
- Deskripsi (khusus karya dosen)

Pencarian bekerja di seluruh jenis karya secara bersamaan.

### Filter Jenis Karya

Pilih jenis karya untuk menampilkan kategori tertentu:

**Penelitian & Pengabdian:**
- `Penelitian` — Penelitian hibah
- `Pengabdian` — Pengabdian kepada masyarakat hibah

**Skripsi:**
- `Skripsi` — Skripsi mahasiswa

**Karya Dosen:**
- `Buku` — Buku yang diterbitkan
- `Modul Ajar` — Modul atau bahan ajar
- `HKI/Paten` — Hak Kekayaan Intelektual atau Paten
- `Penelitian Mandiri` — Penelitian mandiri dosen
- `Pengabdian Mandiri` — Pengabdian mandiri dosen

### Filter Tahun

Pilih tahun untuk menampilkan karya yang diterbitkan pada tahun tertentu.

### Filter Program Studi

Pilih program studi untuk menampilkan karya dari prodi tertentu.

> Filter Program Studi hanya berlaku untuk Penelitian, Pengabdian, dan Skripsi. Karya Dosen tidak terkait dengan program studi tertentu.

## Halaman Detail Karya

Setiap karya memiliki halaman detail yang menampilkan informasi lengkap.

### Detail Penelitian & Pengabdian

Informasi yang ditampilkan:
- **Cover** (jika ada)
- **Judul**
- **Jenis** (Penelitian / Pengabdian)
- **Ketua Peneliti** + tim anggota
- **Program Studi**
- **Tahun**
- **Abstrak**
- **Kata Kunci**
- **Daftar Pustaka** (jika ada)

**File yang dapat diunduh** (setelah login):
- Laporan Final (PDF)
- Paper/Artikel (PDF, jika ada)

### Detail Skripsi

Informasi yang ditampilkan:
- **Cover** (jika ada)
- **Judul**
- **Mahasiswa** (nama & NIM)
- **Program Studi**
- **Tahun**
- **Pembimbing 1 & 2**
- **Abstrak**
- **Kata Kunci**
- **Daftar Pustaka** (jika ada)

**File yang dapat diunduh** (setelah login):
- Skripsi Lengkap (PDF)
- Proposal (PDF, jika tersedia)

### Detail Karya Dosen

Informasi yang ditampilkan:
- **Cover** (jika ada)
- **Judul**
- **Jenis Karya**
- **Penulis** (nama dosen)
- **Tahun**
- **Deskripsi**
- **Kata Kunci**
- **Penerbit** (jika ada)
- **ISBN/ISSN** (jika ada, untuk buku/jurnal)
- **No. HKI** (jika ada, untuk HKI/paten)
- **Tanggal Terbit** (jika ada)

**File yang dapat diunduh** (setelah login):
- File Utama (PDF/DOC/DOCX/JPG/PNG)
- File Pendukung (jika ada)

## Cara Mengunduh File

### Persyaratan

- Pengguna **harus login** terlebih dahulu
- Karya harus sudah **dipublikasikan** di repository

### Langkah-langkah

1. Login ke aplikasi menggunakan akun dosen, mahasiswa, atau staff.
2. Buka halaman detail karya yang ingin diunduh.
3. Scroll ke bagian **File yang Tersedia**.
4. Klik tombol **Download [Nama File]**.
5. File akan terunduh otomatis ke perangkat Anda.

> File yang tersimpan sebagai **link Google Drive** (proposal, laporan kemajuan) **tidak dapat diunduh** dari repository. Hanya file yang diupload langsung ke sistem yang tersedia untuk diunduh.

## Batasan & Ketentuan

### Untuk Pengunjung Umum

- Dapat melihat daftar dan detail karya
- **Tidak dapat** mengunduh file lengkap
- **Tidak perlu** membuat akun untuk melihat abstrak dan informasi umum

### Untuk Pengguna Terdaftar

- Dapat mengunduh file lengkap setelah login
- Tidak ada batasan jumlah download
- File download otomatis diberi nama sesuai judul karya

### File yang Tidak Tersedia di Repository

Beberapa dokumen **tidak** tersedia untuk diunduh dari repository:

**Penelitian & Pengabdian:**
- Proposal awal (link Google Drive)
- Laporan Kemajuan (link Google Drive)
- Laporan Akhir sebelum revisi (link Google Drive)
- LPJ (link Google Drive)

Hanya **Laporan Final** dan **Paper Final** yang dapat diunduh.

**Skripsi:**
- File pengajuan proposal (link Google Drive)
- File revisi proposal (link Google Drive)
- Dokumen bimbingan (link Google Drive)

Hanya **Skripsi Final** yang dapat diunduh dari repository.

**Karya Dosen:**
- Semua file yang diupload (utama & pendukung) dapat diunduh.

## Tampilan Repository

### Halaman Utama Repository

Halaman utama menampilkan:
- **Kotak pencarian** di bagian atas
- **Filter** jenis, tahun, dan program studi
- **Grid karya** dengan tampilan card:
  - Cover/thumbnail
  - Judul
  - Penulis/Peneliti
  - Tahun
  - Tombol **Lihat Detail**
- **Pagination** untuk navigasi halaman

### Urutan Tampilan

Karya ditampilkan berdasarkan:
1. **Tanggal publikasi** (terbaru di atas)
2. Jika filter jenis aktif, hanya karya dari jenis tersebut yang tampil

---

## Tips Penggunaan

### Untuk Pencarian Efektif

1. Gunakan kata kunci spesifik, misal: "machine learning", "pertanian", "pendidikan"
2. Kombinasikan pencarian dengan filter jenis atau tahun
3. Jika hasil terlalu banyak, tambahkan filter program studi

### Untuk Pengunjung Eksternal

- Bookmark halaman repository untuk akses cepat
- Bagikan link halaman detail karya untuk referensi
- Hubungi admin untuk permintaan akses file jika tidak memiliki akun

### Untuk Pengguna Terdaftar

- Login terlebih dahulu sebelum browsing untuk akses penuh
- Unduh file yang diperlukan untuk referensi offline
- Gunakan fitur pencarian untuk menemukan karya spesifik dengan cepat

---

## URL Repository

- **Halaman Utama:** `/` atau `/repository`
- **Detail Penelitian:** `/repository/penelitian/{id}`
- **Detail Skripsi:** `/repository/skripsi/{id}`
- **Detail Karya Dosen:** `/repository/karya-dosen/{id}`

Semua URL di atas dapat diakses tanpa login, kecuali untuk endpoint download yang memerlukan autentikasi.
