1. Pendahuluan & Tentang Aplikasi

Al-Jawami Smart Campus (ASC) adalah sistem informasi akademik terpadu yang dirancang untuk mendukung seluruh proses administrasi dan akademik di Universitas Al-Jawami. Sistem ini menggabungkan berbagai modul dalam satu platform terintegrasi yang dapat diakses melalui browser web maupun diinstal sebagai aplikasi di perangkat mobile dan desktop.

1.1 Fitur Utama

  • Manajemen Akademik — KRS, jadwal perkuliahan, presensi, penilaian, KHS & transkrip
  • Kurikulum OBE — Kurikulum berbasis Outcome-Based Education, RPKPS/RPS digital
  • PMB Online — Pendaftaran mahasiswa baru secara daring dengan berbagai jalur seleksi
  • Keuangan — Tagihan, pembayaran, dan beasiswa mahasiswa
  • Penelitian & Pengabdian — Pengelolaan karya dosen, hibah penelitian, publikasi
  • Skripsi & TA — Manajemen tugas akhir dengan alur persetujuan digital
  • Repository Digital — Perpustakaan digital karya ilmiah yang dapat diakses publik
  • Alumni & Tracer Study — Pengelolaan data alumni dan survey penelusuran lulusan
  • Laporan & Analitik — Dashboard statistik untuk pengambilan keputusan

1.2 Persyaratan Teknis

KomponenPersyaratan
BrowserChrome 90+, Firefox 88+, Edge 90+, Safari 14+
Koneksi InternetMinimal 1 Mbps (untuk akses optimal)
PerangkatDesktop, laptop, tablet, atau smartphone
Resolusi LayarMinimal 360px (mobile) / 1024px (desktop)

2. Cara Mengakses & Login

2.1 Membuka Aplikasi

Buka browser dan ketikkan alamat URL aplikasi ASC yang diberikan oleh administrator institusi.

💡 Info Halaman awal akan menampilkan logo institusi dan form login. Jika logo belum muncul, tunggu beberapa detik hingga data institusi selesai dimuat.

2.2 Proses Login

1

Masukkan Email

Ketik alamat email yang telah didaftarkan oleh administrator sistem.

2

Masukkan Password

Ketik password Anda. Password bersifat case-sensitive (huruf besar dan kecil dibedakan).

3

Klik Tombol Masuk

Klik tombol Masuk atau tekan Enter. Sistem akan memverifikasi kredensial dan mengarahkan ke Dashboard.

⚠️ Perhatian Jika muncul pesan "Login gagal", pastikan email dan password sudah benar. Hubungi administrator jika Anda lupa password.

2.3 Keamanan Sesi

Sesi login berlaku selama 120 menit sejak aktivitas terakhir. Setelah itu, sistem akan meminta login ulang secara otomatis untuk menjaga keamanan data.

3. Instalasi Aplikasi (PWA)

ASC mendukung Progressive Web App (PWA) — aplikasi dapat diinstal di perangkat Anda layaknya aplikasi native tanpa perlu mengunduh dari App Store.

3.1 Instalasi di Desktop (Chrome / Edge)

1

Buka Aplikasi di Browser

Akses URL aplikasi ASC di Chrome atau Edge.

2

Klik Ikon Install

Perhatikan ikon Install (⊕) di sebelah kanan address bar, atau buka menu browser → Install Al-Jawami Smart Campus.

3

Konfirmasi Instalasi

Klik Install pada dialog yang muncul. Aplikasi akan terbuka di jendela tersendiri.

3.2 Instalasi di Android (Chrome)

1

Buka di Chrome Android

Akses URL aplikasi ASC menggunakan Chrome di Android.

2

Tap Banner atau Menu

Jika muncul banner "Tambahkan ke layar utama", tap banner tersebut. Atau buka menu (⋮) → Tambahkan ke layar utama.

3

Konfirmasi

Tap Tambahkan. Ikon ASC akan muncul di layar utama perangkat Anda.

✅ Manfaat PWA Setelah diinstal, aplikasi dapat dibuka lebih cepat, memiliki tampilan fullscreen, dan tetap menampilkan halaman terakhir meski koneksi terputus sementara.

4. Navigasi & Antarmuka

4.1 Layout Utama

Antarmuka ASC terdiri dari beberapa bagian utama:

  • Sidebar (kiri) — Menu navigasi utama yang berisi semua modul sesuai hak akses pengguna
  • Header (atas) — Menampilkan nama pengguna, notifikasi, dan akses profil
  • Area Konten (tengah) — Tempat tampilan halaman aktif

4.2 Navigasi Sidebar

Menu di sidebar ditampilkan berdasarkan role dan permission yang dimiliki pengguna. Klik menu yang memiliki tanda panah (▶) untuk memperluas sub-menu.

4.3 Tombol Aksi Umum

TombolFungsi
+ TambahMenambahkan data baru
✏️ EditMengubah data yang sudah ada
🗑️ HapusMenghapus data (biasanya meminta konfirmasi)
📥 ExportMengunduh data dalam format Excel/PDF
📤 ImportMengunggah data dari file Excel

5. Peran Pengguna (Role)

Setiap pengguna ASC memiliki satu atau lebih peran yang menentukan fitur apa saja yang dapat diakses.

👑 SUPER_ADMIN

Akses penuh ke seluruh sistem. Mengelola konfigurasi, pengguna, dan semua data.

🏛️ PIMPINAN

Melihat semua data dan laporan analitik untuk keperluan pengambilan keputusan.

📚 ADMIN_AKADEMIK

Mengelola semua data akademik: mahasiswa, jadwal, nilai, kurikulum, wisuda.

🎓 ADMIN_PMB

Mengelola proses penerimaan mahasiswa baru: pendaftaran, seleksi, verifikasi.

💰 ADMIN_KEUANGAN

Mengelola tagihan, pembayaran, dan beasiswa mahasiswa.

🗂️ KAPRODI

Mengelola akademik program studi: kurikulum, KRS, kelas, persetujuan RPS.

👨‍🏫 DOSEN

Input presensi, nilai, membuat RPS, mengelola skripsi bimbingan, karya ilmiah.

🤝 DOSEN_WALI

Perwalian akademik: menyetujui KRS, bimbingan, memantau perkembangan mahasiswa.

🎒 MAHASISWA

Mengisi KRS, melihat jadwal, nilai, KHS, mengajukan cuti, mendaftar wisuda.

🏅 ALUMNI

Melihat data alumni, mengisi tracer study, mengakses repository.

📊 LPM

Lembaga Penjaminan Mutu: audit akademik dan pelaporan mutu.

🔬 LP2M

Lembaga Penelitian: verifikasi karya dosen, publikasi repository, kelola KKN.

6.2 Mengelola Tahun Akademik

1

Buka Menu Tahun Akademik

Klik Master Data → Tahun Akademik di sidebar.

2

Tambah Tahun Akademik Baru

Klik tombol + Tambah, isi nama (contoh: "Tahun Akademik 2025/2026"), tanggal mulai dan selesai.

3

Aktifkan Tahun Akademik

Centang Aktif pada tahun akademik yang sedang berjalan. Hanya satu yang dapat aktif dalam satu waktu.

⚠️ Penting Pastikan selalu ada satu Tahun Akademik yang berstatus Aktif. Banyak fitur sistem bergantung pada data tahun akademik aktif.
