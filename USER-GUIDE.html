1. Pendahuluan & Tentang Aplikasi

Al-Jawami Smart Campus (ASC) adalah sistem informasi akademik terpadu yang dirancang untuk mendukung seluruh proses administrasi dan akademik di STAI Yapata Al-Jawami. Sistem ini menggabungkan berbagai modul dalam satu platform terintegrasi yang dapat diakses melalui browser web maupun diinstal sebagai aplikasi di perangkat mobile dan desktop.

1.1 Fitur Utama

  • Manajemen Akademik — KRS, jadwal perkuliahan, presensi, penilaian, KHS & transkrip
  • Kurikulum OBE — Kurikulum berbasis Outcome-Based Education, RPKPS/RPS digital
  • PMB Online — Pendaftaran mahasiswa baru secara daring dengan berbagai jalur seleksi
  • Keuangan — Tagihan, pembayaran, dan beasiswa mahasiswa
  • Penelitian & Pengabdian — Pengelolaan karya dosen, hibah penelitian, publikasi
  • Skripsi & TA — Manajemen tugas akhir dengan alur persetujuan digital
  • Repository Digital — Perpustakaan digital karya ilmiah yang dapat diakses publik
  • Alumni & Tracer Study — Pengelolaan data alumni dan survey penelusuran lulusan
  • Laporan & Analitik — Dashboard statistik untuk pengambilan keputusan

1.2 Persyaratan Teknis

KomponenPersyaratan

Koneksi InternetMinimal 1 Mbps (untuk akses optimal)
PerangkatDesktop, laptop, tablet, atau smartphone

2. Cara Mengakses & Login

2.1 Membuka Aplikasi

Buka browser dan ketikkan alamat URL aplikasi ASC yang diberikan oleh administrator institusi.

💡 Info Halaman awal akan menampilkan logo institusi dan form login. Jika logo belum muncul, tunggu beberapa detik hingga data institusi selesai dimuat.

2.2 Proses Login

1

Masukkan Email

Ketik alamat email yang telah didaftarkan oleh administrator sistem.

2

Masukkan Password

Ketik password Anda. Password bersifat case-sensitive (huruf besar dan kecil dibedakan).

3

Klik Tombol Masuk

Klik tombol Masuk atau tekan Enter. Sistem akan memverifikasi kredensial dan mengarahkan ke Dashboard.

⚠️ Perhatian Jika muncul pesan "Login gagal", pastikan email dan password sudah benar. Hubungi administrator jika Anda lupa password.

2.3 Keamanan Sesi

Sesi login berlaku selama 120 menit sejak aktivitas terakhir. Setelah itu, sistem akan meminta login ulang secara otomatis untuk menjaga keamanan data.

3. Instalasi Aplikasi (PWA)

ASC mendukung Progressive Web App (PWA) — aplikasi dapat diinstal di perangkat Anda layaknya aplikasi native tanpa perlu mengunduh dari App Store.

3.1 Instalasi di Desktop (Chrome / Edge)

1

Buka Aplikasi di Browser

Akses URL aplikasi ASC di Chrome atau Edge.

2

Klik Ikon Install

Perhatikan ikon Install (⊕) di sebelah kanan address bar, atau buka menu browser → Install Al-Jawami Smart Campus.

3

Konfirmasi Instalasi

Klik Install pada dialog yang muncul. Aplikasi akan terbuka di jendela tersendiri.

3.2 Instalasi di Android (Chrome)

1

Buka di Chrome Android

Akses URL aplikasi ASC menggunakan Chrome di Android.

2

Tap Banner atau Menu

Jika muncul banner "Tambahkan ke layar utama", tap banner tersebut. Atau buka menu (⋮) → Tambahkan ke layar utama.

3

Konfirmasi

Tap Tambahkan. Ikon ASC akan muncul di layar utama perangkat Anda.

✅ Manfaat PWA Setelah diinstal, aplikasi dapat dibuka lebih cepat, memiliki tampilan fullscreen, dan tetap menampilkan halaman terakhir meski koneksi terputus sementara.

4. Navigasi & Antarmuka

4.1 Layout Utama

Antarmuka ASC terdiri dari beberapa bagian utama:

  • Sidebar (kiri) — Menu navigasi utama yang berisi semua modul sesuai hak akses pengguna
  • Header (atas) — Menampilkan nama pengguna, notifikasi, dan akses profil
  • Area Konten (tengah) — Tempat tampilan halaman aktif

4.2 Navigasi Sidebar

Menu di sidebar ditampilkan berdasarkan role dan permission yang dimiliki pengguna. Klik menu yang memiliki tanda panah (▶) untuk memperluas sub-menu.

5. Peran Pengguna (Role)

Setiap pengguna ASC memiliki satu atau lebih peran yang menentukan fitur apa saja yang dapat diakses.

👑 SUPER_ADMIN

Akses penuh ke seluruh sistem. Mengelola konfigurasi, pengguna, dan semua data.

🏛️ PIMPINAN

Melihat semua data dan laporan analitik untuk keperluan pengambilan keputusan.

📚 ADMIN_AKADEMIK

Mengelola semua data akademik: mahasiswa, jadwal, nilai, kurikulum, wisuda.

🎓 ADMIN_PMB

Mengelola proses penerimaan mahasiswa baru: pendaftaran, seleksi, verifikasi.

💰 ADMIN_KEUANGAN

Mengelola tagihan, pembayaran, dan beasiswa mahasiswa.

🗂️ KAPRODI

Mengelola akademik program studi: kurikulum, KRS, kelas, persetujuan RPS.

👨‍🏫 DOSEN

Input presensi, nilai, membuat RPS, mengelola skripsi bimbingan, karya ilmiah.

🤝 DOSEN_WALI

Perwalian akademik: menyetujui KRS, bimbingan, memantau perkembangan mahasiswa.

🎒 MAHASISWA

Mengisi KRS, melihat jadwal, nilai, KHS, mengajukan cuti, mendaftar wisuda.

🏅 ALUMNI

Melihat data alumni, mengisi tracer study, mengakses repository.

📊 LPM

Lembaga Penjaminan Mutu: audit akademik dan pelaporan mutu.

🔬 LP2M

Lembaga Penelitian: verifikasi karya dosen, publikasi repository, kelola KKN.

7. Modul SDM (Mahasiswa, Dosen, Staff)

Modul SDM digunakan untuk mengelola data seluruh civitas akademika. Diakses melalui menu SDM di sidebar.

7.1 Data Mahasiswa

Menu: SDM → Mahasiswa

  • Menampilkan daftar mahasiswa dengan filter berdasarkan prodi, angkatan, dan status
  • Klik nama mahasiswa untuk melihat detail (profil, alamat, orang tua, riwayat pendidikan, dokumen)
  • Fitur Import Excel tersedia untuk input data massal
  • Fitur Export Excel untuk mengunduh daftar mahasiswa

7.2 Data Dosen

Menu: SDM → Dosen

  • Daftar dosen lengkap dengan NIDN, jabatan fungsional, dan status
  • Halaman detail dosen berisi: data pribadi, jabatan struktural, karya ilmiah
  • Jabatan Struktural — di halaman detail dosen, Anda dapat menambah/menghapus jabatan (Ketua, WK, Kaprodi, Dosen Wali, dll). Jabatan menentukan hak akses tambahan

7.3 Tenaga Kependidikan

Menu: SDM → Tenaga Kependidikan

Mengelola data staff non-dosen (admin, laboran, pustakawan, dll). Mendukung import/export Excel.

💡 Jabatan Struktural Jabatan seperti Ketua, Wakil Ketua, Kaprodi, dan Dosen Wali bukan "role" terpisah, melainkan jabatan yang melekat pada data dosen. Satu dosen bisa memiliki beberapa jabatan sekaligus, dan setiap jabatan memberikan hak akses tambahan secara otomatis.

10. Modul Perkuliahan & Ujian

Mengelola aktivitas perkuliahan harian: presensi, jurnal pertemuan, dan ujian online.

10.1 Kelas & Pertemuan

Setiap kelas memiliki halaman detail yang berisi:

  • Daftar Mahasiswa — anggota kelas yang terdaftar via KRS
  • Jurnal Pertemuan — catatan setiap pertemuan (topik, materi, metode)
  • Presensi — rekap kehadiran per pertemuan (Hadir, Izin, Sakit, Alpha)
  • Jadwal — hari, jam, dan ruangan perkuliahan

10.2 Presensi

Dosen membuka presensi untuk setiap pertemuan. Mahasiswa tercatat hadir/tidak hadir. Dosen dapat meng-edit presensi jika ada koreksi.

10.3 Bank Soal

Menu: Akademik → Bank Soal

Dosen menyimpan soal-soal yang dapat digunakan berulang kali untuk berbagai ujian:

  • Tipe soal: Pilihan Ganda, Benar/Salah, Esai, Studi Kasus, Matching, Upload File
  • Soal bisa diberi tag dan tingkat kesulitan (Mudah, Sedang, Sulit)
  • Soal dari bank soal bisa di-impor ke ujian online

10.4 Ujian Online

Fitur ujian berbasis komputer yang terintegrasi dengan kelas:

  • Dosen membuat ujian dengan durasi, tanggal mulai/selesai, dan soal
  • Mahasiswa mengerjakan ujian langsung di aplikasi
  • Hasil otomatis dinilai untuk soal objektif (pilihan ganda, benar/salah)
  • Soal esai dinilai manual oleh dosen

12. Modul Bimbingan Akademik

12.1 Fitur Bimbingan

  • Dashboard Bimbingan — ringkasan mahasiswa bimbingan dan progress mereka

  • Catatan Akademik — rekam jejak akademik mahasiswa (IPK, keaktifan, masalah)
  • Peringatan Akademik — mahasiswa yang IPK-nya di bawah batas atau masalah presensi

12.2 Alur Bimbingan

1

Mahasiswa mengajukan sesi bimbingan

Melalui menu Bimbingan, mahasiswa membuat permintaan jadwal konsultasi.

2

Dosen Wali menerima & menjadwalkan

Dosen melihat permintaan masuk dan menyetujui jadwalnya.

3

Pelaksanaan & dokumentasi

Setelah bimbingan, dosen mengisi catatan hasil bimbingan sebagai dokumentasi.

14. Modul Penelitian & Pengabdian

Mengelola aktivitas penelitian dan pengabdian masyarakat dosen. Diakses oleh DOSEN dan LP2M.

14.1 Karya Dosen

Menu: Akademik → Karya Dosen

Dosen dapat mendaftarkan karya ilmiah: jurnal, buku, HKI, prosiding, dll. LP2M memverifikasi dan mempublikasikan ke repository.

14.2 Penelitian & Pengabdian

Menu: Akademik → Penelitian & Pengabdian

  • Mengajukan proposal penelitian/pengabdian
  • Mengelola anggota tim penelitian
  • Upload laporan kemajuan dan laporan akhir
  • Tracking status: Draft → Diajukan → Review → Diterima → Berjalan → Selesai

14.3 Periode Hibah

Menu: Akademik → Periode Hibah

LP2M/Admin mengatur periode pendanaan penelitian: sumber dana, kuota, batas waktu pengajuan.

14.4 Praktikum / KKN / PPL

Menu: Akademik → Praktikum / KKN

Mengelola program praktik lapangan:

  • Membuat program (KKN, PPL, Magang, Praktikum, PKL)
  • Mendata peserta, lokasi, dan pembimbing
  • Tracking progress dan penilaian

17. Pengaturan & Manajemen Pengguna

Menu: Pengaturan — diakses oleh SUPER_ADMIN dan ADMIN_AKADEMIK.

17.1 Manajemen Pengguna

Menu: Pengaturan → Pengguna

  • Melihat daftar seluruh akun pengguna sistem
  • Membuat akun baru dan assign role
  • Menonaktifkan/mengaktifkan akun
  • Reset password pengguna

17.2 Audit Log

Menu: Pengaturan → Audit Log

Mencatat seluruh aktivitas pengguna di sistem: siapa melakukan apa, kapan, dan data apa yang berubah. Berguna untuk audit keamanan dan pelacakan masalah.

17.3 Repository

Menu: Repository (dapat diakses semua pengguna termasuk publik)

Perpustakaan digital yang berisi karya ilmiah (skripsi, jurnal, prosiding) yang sudah dipublikasikan. Dapat diakses tanpa login untuk keperluan referensi.

Buka Akademik → Skripsi / TA → klik Ajukan Judul Baru. Isi judul, abstrak singkat, dan latar belakang. Tunggu persetujuan dari Kaprodi.

20.1 Pertanyaan Umum

PertanyaanJawaban
Lupa password, bagaimana cara reset?Hubungi administrator (SUPER_ADMIN atau ADMIN_AKADEMIK) untuk direset melalui menu Pengaturan → Pengguna.
Mengapa saya tidak bisa mengakses menu tertentu?Menu ditampilkan berdasarkan role dan jabatan Anda. Hubungi admin jika merasa hak akses Anda kurang.
KRS saya sudah diajukan tapi belum disetujui, apa yang harus dilakukan?Hubungi Dosen Wali Anda. KRS menunggu persetujuan Dosen Wali terlebih dahulu, kemudian Kaprodi.
Bagaimana cara install aplikasi di HP?Buka ASC di Chrome → tap menu (⋮) → Tambahkan ke layar utama. Lihat Bab 3 untuk detail.

QR code di dokumen PDF tidak bisa di-scan?Pastikan kualitas cetak cukup jelas. QR code mengarah ke halaman verifikasi online yang bisa diakses siapapun.
Bagaimana cara menambah jabatan struktural dosen?Buka SDM → Dosen → klik nama dosen → scroll ke "Jabatan Struktural" → klik "+ Tambah Jabatan".

23. Integrasi LMS

  1. Isi Base URL API LMS (contoh: https://lms.stai-aljawami.ac.id/api)
