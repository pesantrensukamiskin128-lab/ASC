1. Pendahuluan

Modul KKN/Praktikum pada aplikasi Al-Jawami Smart Campus (ASC) dirancang untuk mengelola seluruh proses kegiatan lapangan mahasiswa, mulai dari pendaftaran, penempatan, pelaksanaan kegiatan harian, hingga pelaporan dan penilaian akhir.

Modul ini mendukung beberapa jenis program:

Jenis ProgramKeterangan
KKNKuliah Kerja Nyata — pengabdian masyarakat
PPLPraktik Pengalaman Lapangan — praktik mengajar
MAGANGMagang / Internship di instansi/perusahaan
PRAKTIKUMPraktikum mata kuliah tertentu
PKLPraktik Kerja Lapangan
ℹ️ Catatan: Seluruh jenis program menggunakan alur yang sama. Perbedaan hanya pada penamaan dan konteks kegiatan.

3.1 Tahap Persiapan (Admin/Koordinator)

  1. Admin membuat program baru (nama, jenis, semester, jadwal)
  2. Admin menambahkan lokasi penempatan
  3. Admin membuat kelompok dan assign lokasi + pembimbing
  4. Admin mendaftarkan peserta ke kelompok & lokasi

3.2 Tahap Pelaksanaan (Mahasiswa)

  1. Mahasiswa mengisi logbook kegiatan setiap hari
  2. Mahasiswa mencatat presensi harian
  3. Dosen pembimbing mereview dan meng-approve logbook

3.3 Tahap Pelaporan & Penilaian

  1. Mahasiswa menyusun dan submit laporan akhir
  2. Dosen pembimbing mereview laporan (approve/revisi)
  3. Dosen pembimbing menginput nilai per komponen
  4. Status peserta diubah menjadi SELESAI

4. Panduan Admin — Membuat Program

Langkah-langkah:

Langkah 1: Masuk ke menu Akademik → Praktikum / KKN
Langkah 2: Klik tombol "Buat Program" di pojok kanan atas
Langkah 3: Isi formulir program:
  • Nama Program — contoh: "KKN Reguler 2026"
  • Jenis — pilih: KKN / PPL / MAGANG / PRAKTIKUM / PKL
  • Semester — pilih semester pelaksanaan
  • Program Studi — kosongkan jika lintas prodi
  • Periode Pendaftaran — tanggal buka & tutup pendaftaran
  • Periode Pelaksanaan — tanggal mulai & selesai program
  • Bobot SKS — jumlah SKS yang didapat peserta
  • Min SKS — syarat minimal SKS untuk mendaftar
  • Koordinator — dosen penanggung jawab program
Langkah 4: Centang "Aktifkan program" lalu klik Simpan
⚠️ Penting: Program yang sudah memiliki peserta tidak dapat dihapus. Nonaktifkan saja jika tidak digunakan lagi.

5. Panduan Admin — Kelola Lokasi Penempatan

Setelah program dibuat, tambahkan lokasi-lokasi penempatan peserta.

Langkah 1: Buka detail program → klik tab "Lokasi"
Langkah 2: Klik "Tambah Lokasi"
Langkah 3: Isi data lokasi:
  • Nama Lokasi — contoh: "Desa Cikadut", "SMP Negeri 5 Bandung"
  • Alamat — alamat lengkap lokasi
  • Kota — kota/kabupaten
  • Kapasitas — jumlah maksimal peserta di lokasi ini
  • Kontak — nama contact person di lokasi
  • No. HP — nomor telepon contact person
  • Dosen Pembimbing Lapangan — dosen yang bertanggung jawab di lokasi ini
Langkah 4: Klik Simpan

6. Panduan Admin — Kelola Kelompok

Kelompok digunakan untuk mengelompokan peserta agar lebih mudah dikelola.

Langkah 1: Buka detail program → klik tab "Kelompok"
Langkah 2: Klik "Tambah Kelompok"
Langkah 3: Isi data:
  • Nama Kelompok — contoh: "Kelompok 1", "Tim A"
  • Lokasi — pilih lokasi penempatan (opsional)
  • Dosen Pembimbing — pilih dosen yang membimbing kelompok ini
Langkah 4: Klik Simpan

7. Panduan Admin — Kelola Peserta

Admin dapat mendaftarkan mahasiswa ke program dan mengatur penempatan mereka.

Langkah 1: Buka detail program → tab "Peserta"
Langkah 2: Klik "Daftarkan Peserta"
Langkah 3: Cari mahasiswa (ketik NIM atau nama), lalu pilih:
  • Kelompok — assign ke kelompok yang sudah dibuat
  • Lokasi — assign ke lokasi penempatan
  • Dosen Pembimbing — pilih pembimbing individu (opsional)
Langkah 4: Klik Daftarkan

Untuk melihat detail peserta (logbook, presensi, nilai), klik tombol "Detail" pada baris peserta.

ℹ️ Tips: Admin juga dapat mengubah status peserta: TERDAFTAR → AKTIF → SELESAI secara manual melalui halaman detail.

8. Panduan Mahasiswa — Pendaftaran Mandiri

Mahasiswa dapat mendaftar sendiri ke program yang sedang membuka pendaftaran.

Langkah 1: Masuk ke menu Akademik → Praktikum / KKN
Langkah 2: Cari program yang statusnya Aktif dan dalam periode pendaftaran
Langkah 3: Klik tombol "Daftar" pada program yang diinginkan
Langkah 4: Konfirmasi pendaftaran → status Anda akan menjadi TERDAFTAR
⚠️ Syarat Pendaftaran:
  • Program harus dalam status Aktif
  • Tanggal saat ini dalam periode pendaftaran
  • Belum pernah mendaftar ke program yang sama

9. Panduan Mahasiswa — Logbook Harian

Selama pelaksanaan KKN/Praktikum, mahasiswa wajib mengisi logbook kegiatan setiap hari.

Langkah 1: Buka halaman Detail Peserta (dari menu Praktikum → klik program → Detail)
Langkah 2: Pilih tab "Logbook"
Langkah 3: Klik "Tambah Logbook"
Langkah 4: Isi formulir:
  • Tanggal — tanggal kegiatan dilakukan
  • Jam Mulai & Selesai — waktu pelaksanaan (opsional)
  • Kegiatan — deskripsi kegiatan yang dilakukan (wajib)
  • Hasil — output/hasil dari kegiatan (opsional)
Langkah 5: Klik Simpan — logbook akan berstatus SUBMITTED

Setelah submit, dosen pembimbing akan mereview logbook Anda. Status akan berubah menjadi:

  • APPROVED ✓ — logbook disetujui
  • REVISION — perlu diperbaiki, cek catatan dari dosen

10. Panduan Mahasiswa — Presensi

Catat kehadiran Anda setiap hari selama pelaksanaan program.

Langkah 1: Buka halaman Detail Peserta → tab "Presensi"
Langkah 2: Klik "Catat Presensi"
Langkah 3: Pilih tanggal dan status kehadiran:
  • HADIR — hadir di lokasi
  • IZIN — tidak hadir dengan izin
  • SAKIT — tidak hadir karena sakit
  • ALPHA — tidak hadir tanpa keterangan
Langkah 4: Tambahkan catatan jika perlu, lalu klik Simpan
ℹ️ Catatan: Presensi bersifat upsert — jika sudah ada data untuk tanggal yang sama, data akan diperbarui.

11. Panduan Mahasiswa — Submit Laporan Akhir

Setelah masa pelaksanaan selesai, mahasiswa wajib menyusun dan mengumpulkan laporan akhir KKN/Praktikum.

Langkah 1: Buka halaman Detail Peserta → tab "Laporan"
Langkah 2: Klik "Submit Laporan"
Langkah 3: Isi formulir:
  • Judul Laporan — judul lengkap laporan akhir (wajib)
  • Abstrak — ringkasan isi laporan
  • Link File — URL file laporan di Google Drive atau platform lainnya
Langkah 4: Klik Submit — status laporan akan menjadi SUBMITTED
⚠️ Tips:
  • Pastikan link file bisa diakses oleh dosen pembimbing (set sharing ke "Anyone with the link")
  • Jika diminta revisi, perbaiki file lalu submit ulang

Status Laporan:

StatusKeterangan
SUBMITTEDLaporan sudah disubmit, menunggu review dosen
REVISIONPerlu diperbaiki sesuai catatan dosen
APPROVEDLaporan disetujui dan diterima

12. Panduan Dosen — Approve Logbook

Dosen pembimbing dapat mereview logbook yang disubmit oleh peserta bimbingannya.

Langkah 1: Masuk ke menu Akademik → Praktikum / KKN
Langkah 2: Buka program yang dibimbing → tab "Peserta" → klik "Detail" pada peserta
Langkah 3: Pada tab "Logbook", lihat daftar logbook berstatus SUBMITTED
Langkah 4: Pilih tindakan:
  • Klik ✓ (centang hijau) untuk menyetujui logbook
  • Klik ✕ (silang kuning) untuk meminta revisi

13. Panduan Dosen — Review Laporan

Setelah mahasiswa submit laporan akhir, dosen pembimbing mereview dan memutuskan apakah laporan diterima atau perlu revisi.

Langkah 1: Buka detail peserta → tab "Laporan"
Langkah 2: Klik laporan yang berstatus SUBMITTED
Langkah 3: Pilih tindakan:
  • Approve — laporan diterima, status berubah ke APPROVED
  • Revision — laporan perlu diperbaiki, tambahkan catatan revisi
ℹ️ Catatan: Saat approve, tanggal persetujuan akan tercatat otomatis beserta nama reviewer.

14. Panduan Dosen — Input Penilaian

Penilaian menggunakan sistem multi-komponen dengan bobot. Dosen dapat menambahkan beberapa komponen penilaian untuk setiap peserta.

Langkah 1: Buka detail peserta → tab "Penilaian"
Langkah 2: Klik "Tambah Komponen"
Langkah 3: Isi data penilaian:
  • Komponen — nama komponen (contoh: Laporan, Presentasi, Kinerja, Disiplin)
  • Nilai (0-100) — skor untuk komponen ini
  • Bobot — bobot relatif komponen (misal: 1, 2, 3)
  • Catatan — keterangan tambahan (opsional)
Langkah 4: Klik Simpan

Contoh Penilaian KKN:

KomponenBobotNilaiBobot × Nilai
Laporan Akhir385255

17. FAQ (Pertanyaan Umum)

Q: Apakah mahasiswa bisa mendaftar ke lebih dari satu program?

Ya, mahasiswa dapat mendaftar ke beberapa program berbeda (misal KKN dan MAGANG). Namun tidak bisa mendaftar dua kali ke program yang sama.

Q: Bagaimana jika mahasiswa lupa mengisi logbook beberapa hari?

Mahasiswa tetap dapat menambahkan logbook untuk tanggal sebelumnya. Tidak ada batasan waktu pengisian.

Q: Apakah dosen bisa menginput presensi untuk mahasiswa?

Ya, dosen (dan admin) memiliki akses untuk mencatat presensi peserta bimbingannya.

Q: Berapa kali mahasiswa bisa submit laporan?

Mahasiswa dapat submit laporan berkali-kali. Setiap submit akan membuat record laporan baru. Biasanya yang terakhir di-approve yang dianggap final.

Q: Bagaimana cara mengubah status peserta menjadi SELESAI?

Admin atau dosen pembimbing dapat mengubah status peserta melalui halaman detail peserta → edit status menjadi SELESAI.

Q: Apakah nilai otomatis masuk ke transkrip?

Saat ini penilaian di modul KKN/Praktikum bersifat internal. Untuk memasukkan nilai ke transkrip, admin perlu menginput nilai final di modul Input Nilai menggunakan mata kuliah yang sesuai.

Q: Bagaimana jika pendaftaran sudah ditutup tapi ada mahasiswa yang belum terdaftar?

Admin tetap dapat mendaftarkan mahasiswa secara manual meskipun periode pendaftaran sudah lewat.
